## 一、图的基本概念（必背）
1. **图 = 顶点（Vertex） + 边（Edge）**
2. **有向图**：边有方向（A→B ≠ B→A）
3. **无向图**：边没有方向（A-B = B-A）
4. **权值**：边的“代价/距离/费用”
5. **连通图**：任意两点都能到达
6. **度**
   - 无向图：顶点相连的边数
   - 有向图：入度 + 出度

## 二、图的两种存储结构（C语言必考）
### 1. 邻接矩阵（最容易写）
用 **二维数组** 表示顶点之间的关系。

- 无向图：矩阵对称
- 有向图：不对称
- 有权图：存权值
- 无边：存 0 或 无穷大

**结构定义：**
```c
#define MAXN 100
typedef struct {
    int edge[MAXN][MAXN];  // 边矩阵
    int n;  // 顶点数
    int e;  // 边数
} MGraph;
```

**优点**：查找两点是否连通 O(1)
**缺点**：浪费空间（稀疏图不适合）

---

### 2. 邻接表（最常用、省空间）
每个顶点挂一个**单链表**，存它的邻居。

**结构定义：**
```c
// 边节点
typedef struct EdgeNode {
    int adjvex;           // 邻接点下标
    int weight;           // 权值
    struct EdgeNode *next;
} EdgeNode;

// 顶点结构
typedef struct VexNode {
    int data;             // 顶点值
    EdgeNode *firstedge;  // 边链表头
} VexNode;

// 整体图
typedef struct {
    VexNode adjList[MAXN];
    int n, e;
} ALGraph;
```

**优点**：省空间、适合稀疏图
**缺点**：判断两点是否连通要遍历链表

## 三、图的两大遍历（超级重点）
### 1. DFS 深度优先搜索（递归）
**像走迷宫，一条路走到底，再回头**

```c
int visited[MAXN];  // 访问标记

void DFS(ALGraph *G, int v) {
    visited[v] = 1;          // 标记已访问
    // 处理顶点v
    
    EdgeNode *p = G->adjList[v].firstedge;
    while(p) {
        if(!visited[p->adjvex])
            DFS(G, p->adjvex);
        p = p->next;
    }
}
```

---

### 2. BFS 广度优先搜索（队列）
**像水波扩散，先近后远**

```c
void BFS(ALGraph *G, int v) {
    int queue[MAXN], front=0, rear=0;
    visited[v] = 1;
    queue[rear++] = v;
    
    while(front < rear) {
        int cur = queue[front++];
        // 处理cur
        
        EdgeNode *p = G->adjList[cur].firstedge;
        while(p) {
            if(!visited[p->adjvex]) {
                visited[p->adjvex] = 1;
                queue[rear++] = p->adjvex;
            }
            p = p->next;
        }
    }
}
```

## 四、图的三大经典算法（考试必出）
### 1. 最小生成树（无向图）
**让所有点连通，总边权最小**

两种算法：
1. **Prim 算法**（加点法，适合稠密图）
2. **Kruskal 算法**（加边法 + 并查集，适合稀疏图）

---

### 2. 最短路径
1. **Dijkstra**：单源最短路径（无负权）
2. **Floyd**：多源最短路径（三维矩阵，代码最简单）

**Floyd 核心代码（超好记）**
```c
for(k=0; k<n; k++)
  for(i=0; i<n; i++)
    for(j=0; j<n; j++)
        if(dist[i][j] > dist[i][k]+dist[k][j])
            dist[i][j] = dist[i][k]+dist[k][j];
```

---

### 3. 拓扑排序（有向无环图）
- 用途：任务先后顺序、课程安排
- 方法：每次找**入度为0**的点输出

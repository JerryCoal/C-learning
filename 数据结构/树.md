# 数据结构——树（Tree）知识文档

## 1. 树的基础概念

### 1.1 定义

树是一种**非线性的数据结构**，由节点（Node）组成，每个节点可以有零个或多个子节点（Child）。树结构中最重要的特点是 **层级关系**：

* **根节点（Root）**：树的顶端节点。
* **父节点（Parent）**：有子节点的节点。
* **子节点（Child）**：父节点下的节点。
* **叶节点（Leaf）**：没有子节点的节点。
* **兄弟节点（Sibling）**：同一父节点的子节点互为兄弟。
* **深度（Depth）**：从根节点到该节点的路径长度。
* **高度（Height）**：节点到最远叶子节点的最长路径长度。
* **层次（Level）**：从根节点开始，根节点层次为1，其子节点层次为2，依次类推。

### 1.2 特性

1. 节点之间存在**一对一的父子关系**。
2. 树的子树也是树。
3. 树是**递归定义的**：每个节点的子树也是一棵树。
4. 树中没有环路（acyclic）。

## 2. 树的分类

### 2.1 按节点度的不同

* **二叉树（Binary Tree）**：每个节点最多有两个子节点（左子节点和右子节点）。
* **多叉树（Multi-way Tree）**：节点可以有两个以上的子节点。
* **完全二叉树（Complete Binary Tree）**：除了最后一层，其他层的节点都已填满，且最后一层节点靠左。
* **满二叉树（Full Binary Tree）**：每个节点要么没有子节点，要么有两个子节点。
* **平衡二叉树（Balanced Binary Tree）**：每个节点左右子树的高度差不超过1。
* **二叉搜索树（Binary Search Tree, BST）**：对于每个节点，左子树所有节点值小于节点值，右子树所有节点值大于节点值。

### 2.2 特殊树

* **AVL树**：一种自平衡的二叉搜索树，保证查找、插入和删除的时间复杂度为 (O(\log n))。
* **红黑树（Red-Black Tree）**：另一种自平衡二叉搜索树，常用于系统库实现（如Java TreeMap）。
* **B树 / B+树**：用于数据库和文件系统的多叉搜索树，支持高效磁盘存取。
* **堆（Heap）**：

  * **最大堆（Max Heap）**：父节点值大于等于子节点。
  * **最小堆（Min Heap）**：父节点值小于等于子节点。
* **字典树（Trie）**：用于字符串检索和前缀匹配。
* **哈夫曼树** ：给定一组带权叶子结点，构造一棵带权路径长度 WPL 最小的二叉树，叫哈夫曼树（最优二叉树）。
  * 构造规则：把所有叶子权值从小到大排序，每次选权值最小的 2 个结点合并，生成一个新父结点，权值 = 两结点之和，把新父结点放回集合，重复上面步骤，直到只剩 1 个根结点
  * 核心性质（必背）
哈夫曼树没有度为 1 的结点，只有度 0（叶子）、度 2（内部结点）
若有 n个叶子结点，则总结点数：2n−1权越小的叶子层数越深，权越大的叶子层数越浅，哈夫曼树不唯一（同组权值可不同合并顺序），但 WPL 一定相等，哈夫曼编码是前缀编码，用于文件压缩

## 3. 树的表示方法

### 3.1 链式存储

每个节点包含：

* 数据域
* 左子节点指针
* 右子节点指针（对于二叉树）
* 对于多叉树，可用孩子链表或孩子-兄弟表示法

```c
// 二叉树节点结构体示例
typedef struct TreeNode {
    int data;
    struct TreeNode* left;
    struct TreeNode* right;
} TreeNode;
```

### 3.2 顺序存储（数组表示）

* 对于**完全二叉树**常用数组存储。
* 对于节点下标 `i`：

  * 左子节点：`2*i + 1`
  * 右子节点：`2*i + 2`
  * 父节点：`(i-1)/2`

## 4. 树的基本操作

### 4.1 遍历

树的遍历分为**深度优先遍历（DFS）**和**广度优先遍历（BFS）**。

#### 4.1.1 深度优先遍历

1. **前序遍历（Pre-order）**：根 → 左 → 右
2. **中序遍历（In-order）**：左 → 根 → 右（BST中中序遍历结果为升序）
3. **后序遍历（Post-order）**：左 → 右 → 根

```c
// 前序遍历示例(增加深度)
void preOrder(TreeNode* root,int deep) {
    if (root == NULL) return;
    printf("%d %d", root->data,deep);
    preOrder(root->left,deep++);
    preOrder(root->right,deep++);
}


```

#### 4.1.2 广度优先遍历（层次遍历）

* 使用队列实现，从上到下逐层访问节点。

```c
#include <stdio.h>
#include <stdlib.h>

// 你的三叉树节点
typedef struct Node {
    int data;
    int x;
    struct Node *left, *mid, *right;
} node;

// 队列节点（存树节点指针）
typedef struct QNode {
    node* tnode;
    struct QNode* next;
} QNode;

QNode* qFront = NULL;
QNode* qRear  = NULL;

// 入队
void enQueue(node* t)
{
    QNode* newq = (QNode*)malloc(sizeof(QNode));
    newq->tnode = t;
    newq->next  = NULL;
    if(qRear == NULL)
        qFront = qRear = newq;
    else
    {
        qRear->next = newq;
        qRear = newq;
    }
}

// 出队
node* deQueue()
{
    if(qFront == NULL) return NULL;
    QNode* tmp = qFront;
    node* res = tmp->tnode;
    qFront = qFront->next;
    if(qFront == NULL) qRear = NULL;
    free(tmp);
    return res;
}

// 层序遍历 层数遍历
void levelOrder(node* root)
{
    if(root == NULL) return;
    enQueue(root);

    while(qFront != NULL)
    {
        node* cur = deQueue();
        // 访问当前节点
        printf("节点值：%d  x=%d\n", cur->data, cur->x);

        // 左、中、右依次入队，保证层序顺序
        if(cur->left)  enQueue(cur->left);
        if(cur->mid)   enQueue(cur->mid);
        if(cur->right) enQueue(cur->right);
    }
}
```

### 4.2 查找

* 二叉搜索树的查找复杂度：

  * 最坏 (O(n))（退化为链表）
  * 平衡树 (O(\log n))

### 4.3 插入与删除

* **插入**：

  * BST：找到合适位置，插入节点
  * 平衡树：插入后可能需要旋转保持平衡
* **删除**：

  * BST 删除节点分三种情况：

    1. 无子节点 → 直接删除
    2. 有一个子节点 → 子节点替代
    3. 有两个子节点 → 找右子树最小值替代，再删除右子树最小值节点

## 6. 树的应用

1. **表达式树**：用于解析和计算算术表达式
2. **文件系统**：目录结构常用树表示
3. **数据库索引**：B树/B+树用于快速查找
4. **路由表**：Trie树用于快速前缀匹配
5. **优先队列**：堆实现
6. **人工智能**：决策树、博弈树
7. **编译原理**：语法树（AST）

核心流程（后缀表达式从左向右遍历）
* 1.遇到数字
* 2.新建数值叶子节点，直接压入节点栈。
* 3.遇到运算符
* 4.新建运算符分支节点
* 5.先出栈一个节点 → 作为右孩子
* 6.再出栈一个节点 → 作为左孩子
* 7.把当前运算符节点压入栈中
* 8.遍历结束
* 9.栈内仅剩唯一一个节点，就是整棵表达式树的根节点。

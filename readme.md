# 标识词识别

## 目标
+ 读取文件里的标准C语言输入
+ 筛选标识词并且按照字符序从小到大储存在word数组里

## 实现过程
+ 1.使用fgets函数读取标准输入，储存在sentence字符串中
+ 2.遍历sentence字符串，识别标识词开头并且一直写入word字符串直到标识词结尾
+ 3.在识别并写入的过程中跳过关键字和重复词、数字字面量
+ 4.通过stdlib库中的qsort()函数排序word[][]
+ 5.最后使用printf函数输出

## 局限
+ 1.没有识别10u，10.0f这类数据的判断
+ 2.没有识别注释// 或者/**/

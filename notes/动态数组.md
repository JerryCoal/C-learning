# 动态数组Vector

## 概念：结合列表和链表的一种数据结构
    链表+ 列表（且列表的容量可以扩容使用realloc函数重新设置容量）

## 实现方法
### 定义
```c
#include <stdio.h>
#include <stdlib.h>

// 定义动态数组结构（vector）
// 这里默认存储 int 类型，你可以改成 float/char 等任意类型
typedef struct {
    int* data;    // 底层存储数据的指针
    size_t size;  // 当前元素个数
    size_t cap;   // 总容量（已分配内存大小）
} Vector;
```
### 实现函数
```c
// 1. 初始化 vector（默认容量 4）
void vec_init(Vector* vec) {
    // 初始分配 4 个 int 空间
    vec->data = (int*)malloc(4 * sizeof(int));
    vec->size = 0;    // 初始没有元素
    vec->cap = 4;     // 初始容量 4
}

// 2. 自动扩容（内部调用，用户无需使用）
void vec_resize(Vector* vec) {
    // 容量翻倍
    vec->cap *= 2;
    // realloc：重新分配更大的连续内存
    vec->data = (int*)realloc(vec->data, vec->cap * sizeof(int));
} 
```

# 文件操作

## 1.文件读取(只用到stdio.h)
```c
FILE *file = fopen(文件名，打开方式)//要注意文件必须放在目录下面，否则要写绝对路径
```
### 1.1打开方式
|模式|具体操作|
|----|-------|
|r|只读|
|w|只写|
|a|追加写|
|r+|写+读|
|rb/wb|二进制形式（视频/图片）

```c
//判断文件是否打印失败

if (fp == NULL) {
    perror("打开失败");
    return 1;
}
```

### 1.2 读取方式 
```c
//按字符读取

char ch;
while ((ch = fgetc(fp)) != EOF) {
    printf("%c", ch);
}

//按行读取
#define max 123123
char line[max];
while (fgets(line, sizeof(line), fp) != NULL) {
    printf("%s", line);
}
//格式化读取,就相当于把文件当成输入

int a, b;
fscanf(fp, "%d %d", &a, &b);

```
## 2.文件操作

### 2.1 写入操作
```c
// 写字符
fputc('A', fp);

// 写字符串
fputs("Hello World\n", fp);

// 格式化写入
fprintf(fp, "%d %s\n", 123, "test");

```

### 2.2 删除操作
```c
//无法直接删除，只能保存想要的字符

#include <stdio.h>
#include <stdlib.h>

int main() {
    FILE *fp = fopen("test.txt", "r");
    FILE *tmp = fopen("tmp.txt", "w");

    if (!fp || !tmp) {
        perror("打开失败");
        return 1;
    }

    int ch;
    // 逐个读字符
    while ((ch = fgetc(fp)) != EOF) {
        // 不删除的才写入临时文件
        if (ch != 'a' && ch != 'A') {
            fputc(ch, tmp);
        }
    }

    fclose(fp);
    fclose(tmp);

    // 删除原文件，临时文件改名
    remove("test.txt");
    rename("tmp.txt", "test.txt");

    return 0;
}
```

### 2.3 关闭操作
```c
fclose(fp);
```

## 3. 其他
    -C 语言创建文件的方法
    -只用 fopen 一个函数就能创建新文件。
    -关键规则
    -打开模式用 "w" 或 "a"
    -如果文件不存在，系统会自动创建
    -如果文件已存在，"w" 会清空内容，"a" 不会清空
